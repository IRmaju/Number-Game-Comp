# 🌟 **Number Guessing Game** 🎮

Welcome to the **Number Guessing Game**! This is a fun, interactive game where you have to guess the random number chosen by the computer. Let's see if you can guess it correctly! 😎

---

## 💻 **How to Run the Game:**

1. **Clone the Repository**:
    ```bash
    git clone https://github.com/YourUsername/Number-Guessing-Game.git
    ```

2. **Navigate to the Project Folder**:
    ```bash
    cd Number-Guessing-Game
    ```

3. **Install the Required Libraries**:
    Make sure you have Python installed, then run:
    ```bash
    pip install -r requirements.txt
    ```

4. **Run the Streamlit App**:
    ```bash
    streamlit run main.py
    ```

This will launch the game in your browser. Enjoy the fun of guessing numbers! 🎉

---

## 🚀 **Technologies Used**:

- **Streamlit**: For building the interactive web app.
- **Python**: Core programming language for game logic.
- **Random Module**: To generate random numbers for guessing.

---

## 🎯 **Game Rules**:

1. A random number between **1 and 100** is chosen by the system.
2. You need to guess the number.
3. If your guess is too low, the game will tell you **"Too low!"**.
4. If your guess is too high, the game will tell you **"Too high!"**.
5. If you guess the right number, you win and get a message like **"Congratulations!"**.
